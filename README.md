# moodle-assignment-checking-helper
In Moodle it's really annoying to check assignments, first because the interface requires a ton of unnecessary clicking, and second because a lot of the times the students have the same mistake that require the same feedback comment. This chrome extension aims to mitigate both of these issues and greatly speed up the process.

In this project there are two projects. A google chrome extension and a visual studio code extension. The chrome extension can run standalone. The vs code extension is supposed to augment using the chrome one.
